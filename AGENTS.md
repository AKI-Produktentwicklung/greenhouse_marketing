# Codex Project Instructions – Greenhouse Assistant

## Project purpose

This repository is primarily a **market-validation and business-research project**.

## Working rules

1. Do not invent market facts, prices, competitors, customer numbers or sources.
2. Clearly distinguish:
   - verified facts
   - estimates
   - hypotheses
   - user-provided information
3. Keep `sources.md` updated whenever external research is added.
4. Prefer primary sources for prices, specifications and company information.
5. Use community sources mainly for pain points, complaints and qualitative evidence.
6. Do not over-focus on technical implementation unless explicitly requested.
7. Preserve strategic decisions in `decisions.md`.
8. Put unresolved items in `open-questions.md`.
9. Avoid duplicating information across many files; link between files where useful.
10. Write all project documentation in German unless explicitly requested otherwise.

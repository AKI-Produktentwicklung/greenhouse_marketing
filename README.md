# Greenhouse Assistant – Research Project

## Ziel

Dieses Repository ist die zentrale Arbeitsbasis für die Marktvalidierung und spätere Produktentwicklung des **Greenhouse Assistant**.

Der Fokus liegt zunächst **nicht auf der technischen Umsetzung**, sondern auf der Frage:

> Gibt es einen ausreichend großen und zahlungsbereiten Markt für eine autonome, modulare Gewächshausautomation im Bereich ca. 10–100 m²?

## Aktueller Produktgedanke

Greenhouse Assistant soll eine robuste, weitgehend autonome Steuerung für hochwertige private Gewächshäuser, Selbstversorger und kleine gewerbliche Produzenten werden.

Kernidee:

- autonomer Betrieb auch ohne Internet
- verkabeltes Grundsystem
- Erweiterungen und weitere Gewächshäuser über WLAN möglich
- Fernüberwachung und Fernsteuerung
- Schutzfunktionen für Sturm, Frost, Überhitzung und Sensorausfall
- Klimaautomation: Lüften, Heizen, Befeuchten, Entfeuchten, Beschatten
- perspektivisch Bewässerung, Datenlogging, Wetterprognosen und KI-gestützte Funktionen
- Plug-and-Play-orientierte Installation für technikinteressierte Anwender
- Zielpreis Grundsystem grob: 700–1.500 EUR
- Ziel: daraus innerhalb von ca. zwei Jahren ein tragfähiges Business entwickeln

## Bestehender Prototyp

Es existiert bereits ein funktionsfähiger Prototyp auf Node-RED-Basis.

- seit ca. drei Jahren im realen Gewächshausbetrieb
- reale Schutzfunktionen wie Sturm- und Frostschutz vorhanden
- Sensor-Fallback bei Ausfall teilweise vorhanden
- lokale Wetterstation eingebunden
- positiver Praxisnutzen besonders bei Abwesenheit und plötzlichen Wetteränderungen
- bisheriger Entwicklungsaufwand grob: ca. 1.000 Stunden
- bisherige Prototypkosten grob: ca. 5.000 EUR

## Arbeitsprinzip

Dieses Projekt trennt bewusst:

1. **Marktproblem**
2. **Zielkunde**
3. **Zahlungsbereitschaft**
4. **Wettbewerb**
5. **Produktlösung**
6. **Technik**

Technische Lösungen werden erst dann vertieft, wenn sie zur Validierung eines Marktproblems notwendig sind.
